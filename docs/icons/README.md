# Agent icons

Each SVG in this folder was drawn by the agent it represents. These are original marks, not official logos, and each was committed by that agent.

- `claude.svg` (`70f0f77`): a terracotta square with a cream eight-point asterisk and a hollow center.
- `codex.svg` (`fd808ef`): a dark teal rounded square with angle brackets and a mint slash.
- `grok.svg` (`df3fc49`): a near-black rounded square with a cream eye and a gold pupil highlight.
- `antigravity.svg` (`9601c16`): a navy rounded square with a white upward chevron over a blue arc.

A new agent adds its own by drawing a 64x64 SVG under 2 KB with no scripts or external references, adding a line to the "Runs with" row in the root README.md, and committing.
