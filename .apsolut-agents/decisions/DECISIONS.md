# DECISIONS — cross-cutting only

Durable record of choices that affect more than one agent's work (shared shapes, schema,
dependencies, test strategy, architecture). **Append-only. Grep it for a topic — never
read it whole.** Stable ids: next = highest existing + 1; gaps allowed, never reuse.

**Close the loop:** when you implement a decision, update its `Status:` line in the same
session. Mark a superseded entry `~~superseded by D-0NN~~` at its top; don't delete it.

Template:
```markdown
### D-0NN — <title>  (<date>)
- **Decision:** …
- **Why:** …
- **Rejected:** …
- **Status:** proposed | final | implemented (<commit>)
- **Owners / applies to:** …
```

### D-001 — Worktrees replace locks as the Tier-2 concurrency mechanism  (2026-07-28)
- **Decision:** Tier 2 = per-agent `git worktree` isolation + a `.primary` pointer file that redirects all coordination reads/writes to the single primary workspace. `locks/` and `CONCURRENCY.md` are deleted. One system, three tiers — no separate "simple" vs "worktrees" editions.
- **Why:** In the only real multi-week run (joyci), locks were never installed and never missed; the old docs themselves called lock files advisory-and-dishonest. Worktrees give real isolation, and the pointer keeps the log/state physically single so agent branches carry zero coordination changes and merges can't conflict on them.
- **Rejected:** a new Tier 3 on top of locks (keeps a mechanism the docs call inferior); gitignoring runtime files (loses committed coordination history); symlinks/junctions (Windows permissions, git confusion).
- **Status:** implemented (e46fabb, 9e373fa)
- **Owners / applies to:** all agents, `template/WORKTREES.md`, `scripts/worktree.sh`

### D-002 — template/ is the payload; the repo root runs a live dogfood instance  (2026-07-28)
- **Decision:** Pristine payload lives in `template/`; this repo installs its own copy at `.apsolut-agents/` and tracks its development there. Every file carries a line-1 label `apsolut-agents: tier=<n> kind=<doc|instance|generated>`; `install.sh --refresh` overwrites `doc`/`generated`, never `instance`.
- **Why:** The joyci run showed fill-in-yourself artifacts stay unfilled unless the project itself demonstrates them; dogfooding surfaces friction before users hit it. The `kind=` label makes upgrade-without-clobbering mechanical instead of a judgment call.
- **Rejected:** shipping the root as the payload (can't dogfood without leaking instance state to users); a scaffold that blanks files on install (must enumerate what to blank — fragile); a dist/build step (violates the no-build soul).
- **Status:** implemented (9e373fa)
- **Owners / applies to:** `install.sh`, every template file, this workspace

### D-003 — Ceremony is pruned to what survived contact; derived facts are script-generated  (2026-07-28)
- **Decision:** Session end = one token heading (`### <agent> — <date> — PUSHED|HOLD|FAILED`) + prose; the old 4-field end block is gone. Log compaction is automated by `session-end.sh` at 400 lines. INTENT is Tier-2-only. `STATUS.md` + the state facts block are generated by `status.sh` from git and work-file frontmatter. Subagent fan-outs must leave one log entry + one `runs/<date>-<slug>.md`.
- **Why:** Evidence from joyci: the mandatory end block was used 0/52 times, compaction never fired at the 150-line social rule (log hit 665), the hand-written state file ended 22 commits stale on 4 load-bearing facts, and a 10-agent run left zero artifacts. Rules that need a human owner don't fire; derived facts can't drift.
- **Rejected:** keeping full ceremony with enforcement hooks (heaviest option, fights the grain); pure-markdown pruning without scripts (leaves the stale-state root cause in place).
- **Status:** implemented (e46fabb, 9e373fa)
- **Owners / applies to:** `template/PROTOCOL.md`, `template/runs/README.md`, all scripts
