# DECISIONS — cross-cutting only

Durable record of choices that affect more than one agent's work (shared shapes, schema,
dependencies, test strategy, architecture). **Append-only. Grep it for a topic — never
read it whole.** Stable ids: next = highest existing + 1; gaps allowed, never reuse.

**Close the loop:** when you implement a decision, update its `Status:` line in the same
session. Mark a superseded entry `~~superseded by D-0NN~~` at its top; don't delete it.

Template:
```markdown
### D-0NN — <title>  (<date>)
- **Decision:** …
- **Why:** …
- **Rejected:** …
- **Status:** proposed | final | implemented (<commit>)
- **Owners / applies to:** …
```

### D-001 — Worktrees replace locks as the Tier-2 concurrency mechanism  (2026-07-28)
- **Decision:** Tier 2 = per-agent `git worktree` isolation + a `.primary` pointer file that redirects all coordination reads/writes to the single primary workspace. `locks/` and `CONCURRENCY.md` are deleted. One system, three tiers — no separate "simple" vs "worktrees" editions.
- **Why:** In the only real multi-week run (joyci), locks were never installed and never missed; the old docs themselves called lock files advisory-and-dishonest. Worktrees give real isolation, and the pointer keeps the log/state physically single so agent branches carry zero coordination changes and merges can't conflict on them.
- **Rejected:** a new Tier 3 on top of locks (keeps a mechanism the docs call inferior); gitignoring runtime files (loses committed coordination history); symlinks/junctions (Windows permissions, git confusion).
- **Status:** implemented (e46fabb, 9e373fa)
- **Owners / applies to:** all agents, `template/WORKTREES.md`, `scripts/worktree.sh`

### D-002 — template/ is the payload; the repo root runs a live dogfood instance  (2026-07-28)
- **Decision:** Pristine payload lives in `template/`; this repo installs its own copy at `.apsolut-agents/` and tracks its development there. Every file carries a line-1 label `apsolut-agents: tier=<n> kind=<doc|instance|generated>`; `install.sh --refresh` overwrites `doc`/`generated`, never `instance`.
- **Why:** The joyci run showed fill-in-yourself artifacts stay unfilled unless the project itself demonstrates them; dogfooding surfaces friction before users hit it. The `kind=` label makes upgrade-without-clobbering mechanical instead of a judgment call.
- **Rejected:** shipping the root as the payload (can't dogfood without leaking instance state to users); a scaffold that blanks files on install (must enumerate what to blank — fragile); a dist/build step (violates the no-build soul).
- **Status:** implemented (9e373fa)
- **Owners / applies to:** `install.sh`, every template file, this workspace

### D-003 — Ceremony is pruned to what survived contact; derived facts are script-generated  (2026-07-28)
- **Decision:** Session end = one token heading (`### <agent> — <date> — PUSHED|HOLD|FAILED`) + prose; the old 4-field end block is gone. Log compaction is automated by `session-end.sh` at 400 lines. INTENT is Tier-2-only. `STATUS.md` + the state facts block are generated by `status.sh` from git and work-file frontmatter. Subagent fan-outs must leave one log entry + one `runs/<date>-<slug>.md`.
- **Why:** Evidence from joyci: the mandatory end block was used 0/52 times, compaction never fired at the 150-line social rule (log hit 665), the hand-written state file ended 22 commits stale on 4 load-bearing facts, and a 10-agent run left zero artifacts. Rules that need a human owner don't fire; derived facts can't drift.
- **Rejected:** keeping full ceremony with enforcement hooks (heaviest option, fights the grain); pure-markdown pruning without scripts (leaves the stale-state root cause in place).
- **Status:** implemented (e46fabb, 9e373fa)
- **Owners / applies to:** `template/PROTOCOL.md`, `template/runs/README.md`, all scripts

### D-004 — Night Shift v0: rule-based, merge-free, kill-is-terminal  (2026-07-29)
- **Decision:** Unattended overnight runs ship as `runner.sh` + `HEARTBEAT.md` policy + `NIGHTSHIFT.md`, per the three-model PRD (`runs/2026-07-29-night-shift-prd.md`): no LLM in the control plane; branches stay unmerged until morning; timeout-kill is terminal (cleanup + retry counter, no resume-as-nudge); cross-model reassign is morning-human-only; claim = `mkdir` mutex + card rewrite with boot-time stale-claim recovery; per-night hard budget cap ($25 default); provider 429s back off instead of tripping the breaker. `after:` edges are sequencing only — dependent cards cannot see unmerged dependency code (proven in the acceptance test).
- **Why:** Both blind reviewers (Gemini, Grok) independently demanded the same four cuts from Claude's draft; convergence of independent reviews outranks the drafter's preferences.
- **Rejected:** stage-2 haiku classifier (both reviews), overnight `night/<date>` integration branch (both), auto-reassign (both), derived-complexity timeouts (no size model exists).
- **Status:** implemented (v0; gates to v1/v2 defined in NIGHTSHIFT.md)
- **Owners / applies to:** `template/scripts/runner.sh`, `template/HEARTBEAT.md`, `template/NIGHTSHIFT.md`, Tier 2

### D-005 — PLAYBOOK: enforce-or-omit delivery practices  (2026-07-29)
- **Decision:** Ship `PLAYBOOK.md` (Tier 1) per the 3-model synthesis (`runs/2026-07-29-playbook-review.md`): small batches; checkable Done-when with a HARD test-first runner gate (`spike: true` = visible waiver); risk tags (`api-contract, schema, pii, money, ui`) instead of B2B/B2C profiles; no metric claims until scripts compute them; fixed-shape blameless blocked notes. Universal rules live in the card template so Tier 0 gets the substance.
- **Why:** Both blind reviewers independently identified unenforced prose as the end-block failure class and market-persona profiles as costume; convergence adopted.
- **Rejected:** DORA-lite section without implementation; B2B/B2C axis; convention-only test-first.
- **Status:** implemented
- **Owners / applies to:** template/PLAYBOOK.md, work/_TEMPLATE.md, scripts/runner.sh

### D-006 — Assimilate buzz's protocol lessons as terse norms + one script mechanism; reject its platform  (2026-07-31)
- **Decision:** From [block/buzz](https://github.com/block/buzz) (production multi-agent platform; its base prompt, orchestrator personas, kickoff postmortem), after a two-round Claude↔Grok adversarial review (`runs/2026-07-31-buzz-review-grok.md`): **one mechanism** — `delegate.sh`/`runner.sh` stamp `green_cmd @ <commit>` into run output before running the check, binding every recorded green/red to its exact commit; **five terse norms** — asymmetric publish + no ack-only entries mid-session, end token always required (`PROTOCOL §1`); evict-on-ship clause (`PROTOCOL §2`); green stated as a claim about a commit + negative claims scoped to places searched (`PROTOCOL §6`); log status is facts off the board, timers are backstops (`DELEGATION §2`); prefer fresh eyes for judgement verdicts, with solo-roster fallback (`DELEGATION §5`); cards state what must be true, not commands, no invented constraints (folded into the existing NIGHTSHIFT bullet). Buzz recorded as a one-paragraph prior-art pointer (reference §12).
- **Why:** Buzz's production failures (agent ack-loop, false timer-driven status announcement, self-reviewed conclusions) are real multi-agent failure modes; Grok's review forced the enforce-or-omit test on every import — what a script can check became a script line (the HEAD stamp), what only review can judge stayed as minimal norms, and everything else was cut. Convergence of adversarial rounds outranks the drafter's preferences (same rule as D-004/D-005).
- **Rejected:** the relay/Nostr/keypair platform (cross-machine problems this workspace doesn't have); "full suite, never scoped" (fights deliberate card scoping and budgets); hard never-self-review duty (fails a solo roster); long in-doc buzz citations (evidence lives here, docs stay terse); persona-pack machinery; charter YAML frontmatter parsed by `delegate.sh` (revisit if the `agents/` ↔ `cmd_<agent>:` duplication bites); "zero prose until a local scar exists" (would delete half of PROTOCOL — norms that define done/green/honest are not the skippable ceremony D-003 pruned).
- **Status:** implemented
- **Owners / applies to:** all agents; template/PROTOCOL.md, template/DELEGATION.md, template/NIGHTSHIFT.md, template/reference/multi-agent-cli-foundations.md, template/scripts/delegate.sh, template/scripts/runner.sh

### D-007 — License is MIT; card filename must equal `<id>.md` (enforced)  (2026-08-11)
- **Decision:** (a) The repo ships under MIT — chosen by the human 2026-08-11; the public `curl | sh` install was legally unusable without a grant. (b) The card contract "filename = `<id>.md`" is now enforced, not etiquette: runner refuses the lane, delegate refuses the card, status.sh warns. Scripts key claims/deps/reports on the filename; discovery by frontmatter `id:` alone is not supported.
- **Why:** A real overnight run (field report, `runs/2026-08-11-field-report-and-pre-merge-review.md`) lost a night to a descriptively-named card that was discovered but silently missed downstream. Enforce-or-omit (D-005) says a checkable rule must be a check.
- **Rejected:** resolving cards by scanning frontmatter everywhere (spreads O(n) scans through every script and keeps two sources of truth); dual-key support (same problem, plus ambiguity when they disagree).
- **Status:** implemented
- **Owners / applies to:** LICENSE; template/scripts/runner.sh, delegate.sh, status.sh; template/work/_TEMPLATE.md
